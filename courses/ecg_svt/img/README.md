# Схемы к курсу ecg_svt

Схемы подключены в course.json: поле `img` на слайдах и блоки `img` в карточках (см. COURSE_FORMAT.md, раздел «Картинки и схемы»).

| Где | Файл | Что на схеме |
|---|---|---|
| слайд 2 (compare, full), карточка 3 | `s02_sinus_vs_svt.svg` | синусовая тахикардия и НЖТ, реакция на вагусную пробу |
| слайд 5, карточка 5 | `s05_es_types.svg` | предсердная, из АВ-соединения и желудочковая ЭС; сцепление и пауза |
| слайд 7, карточка 7 | `s07_threatening.svg` | бигеминия, парные, политопные, ранние ЖЭ |
| слайд 8, карточка 8 | `s08_svt.svg` | пароксизм НЖТ и его признаки |
| слайд 9, карточка 9 | `s09_algorithm.svg` | алгоритм при регулярной тахикардии с узким QRS (КР619_3) |

Параметры: SVG 960×540, белая подложка, шрифт DejaVu Sans / Arial, без внешних ресурсов.
Генератор: `python3 make_svg.py <папка>` (нужен `ecg_lib.py` рядом). Кривые учебные, синтезированы.
