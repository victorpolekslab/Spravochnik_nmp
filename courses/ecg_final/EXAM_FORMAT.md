# Часть `exam`: задачи со свободным ответом (расширение формата 1)

Впервые используется в курсе `ecg_final` («ЭКГ. Итоговое занятие»). Это третья часть курса наряду с `course` и `lecture`:
курс может состоять только из `exam`. Проверка ответов — скриптом `checker.js` из этой папки, без ИИ и без сети.

## Что нужно сделать в разработке

1. **Импортёр** (`tools/course/import_course.py`): принимать курс, где есть только `exam`; проверять поля по правилам ниже; копировать `img/` и `checker.js`.
2. **Лента**: ключ `feed.exam` — строка до 200 символов, как у `course` и `lecture`.
3. **Экран занятия**: интерфейс по разделу «Как показывать», проверка — функциями из `checker.js` (код можно встроить как есть, ES5, ~120 строк).
4. **Тесты**: `node run_tests.js` из этой папки должен печатать `209/209 ok`. Если меняете `checker.js`, прогоняйте тесты.

## Структура

```json
"exam": {
  "min": 40,
  "pass": 0.75,
  "intro": "текст перед началом",
  "tasks": [
    {
      "k": "Задача 1",
      "h": "заголовок без подсказки",
      "facts": ["условие строкой", "..."],
      "img": "img/z01.svg",
      "fields": [ { "l": "Заключение", "need": [["…"]], "ref": "эталон" } ],
      "e": ["разбор пунктами"],
      "src": "КР157_5"
    }
  ]
}
```

| Поле задачи | Обязательно | Что это |
|---|---|---|
| `k`, `h` | да | рубрика и заголовок; заголовок не должен подсказывать ответ |
| `facts` | да | условие, 1–6 строк |
| `img` | нет | лента ЭКГ (SVG 960×540), открывается крупно по нажатию |
| `fields` | да | 1–4 поля ответа |
| `e` | да | разбор, показывается после проверки задачи |
| `src` | нет | `КР<ID>` — ссылка под разбором |

## Поле ответа

| Ключ | Что это |
|---|---|
| `l` | подпись над полем ввода |
| `need` | список групп; в ответе должно быть **хотя бы одно слово из каждой группы** |
| `want` | то же, но для полного балла; не хватает — «Почти» и подсказка `wm` |
| `ban` | `[{r, m, neg?}]`: `r` — регулярное выражение по нормализованному тексту, `m` — пояснение; `neg: true` — не срабатывает, если рядом стоит отрицание («клопидогрел не даём») |
| `bonus`, `bm` | необязательная похвала за дополнительную находку |
| `num` | `[min, max]` — числовой ответ; засчитывается любое число из диапазона (`2,5` и `2.5` одинаково) |
| `alt` | для числового поля — словесные варианты («2 часа», «двое суток») |
| `nm` | подсказка, если ответ неверный |
| `ref` | эталон; показывается после проверки и сам обязан засчитываться (это проверяют тесты) |

**Как скрипт сравнивает слова.** Текст переводится в строчные, «ё» → «е», знаки → пробелы; «СТ» кириллицей в «ИМпСТ» читается как латинское ST.
Термин совпадает, если с него **начинается** слово ответа: «нижн» засчитывает «нижний» и «нижней». В терминах из 6 и более букв прощается одна опечатка.

## Оценка

| Результат `grade()` | Когда | Балл |
|---|---|---|
| `ok` — «Верно» | все `need` и `want` есть, запретов нет | 1 |
| `almost` — «Почти» | все `need` есть, не хватает `want` | 0,5 |
| `error` — «Есть ошибка» | все `need` есть, но сработал запрет | 0 |
| `wrong` — «Неверно» | нет хотя бы одной группы `need` | 0 |
| `empty` | поле пустое — показать «Введите ответ», дальше не проверять | — |

Кнопка **«Мой ответ верный»** (для всех результатов, кроме `ok`) ставит 1 балл и помечает ответ `self: true`.
Итог — `total(results, pass)`: доля баллов от числа полей; зачёт при доле не ниже `pass` (здесь 0,75).

## Как показывать

1. Перед началом — `intro` и число задач.
2. Задача: `k`, `h`, `facts`, лента `img`, поля ввода (одна строка, без автоисправления и подсказок клавиатуры), кнопка «Проверить».
3. После проверки под каждым полем: результат и `msg`, затем «Эталон: …». Поля блокируются, ниже — разбор `e` и ссылка `src`.
4. В конце — счёт, «Зачтено» или «Не зачтено» и список задач с ошибками, к которым можно вернуться посмотреть разбор.
5. Ответы хранятся только на устройстве. Можно собирать незасчитанные ответы, которые человек отметил «Мой ответ верный»: по ним мы будем пополнять синонимы в ключах.
