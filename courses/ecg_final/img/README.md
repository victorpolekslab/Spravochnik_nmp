# ЭКГ к курсу ecg_final

Реальные записи базы PTB-XL (PhysioNet, лицензия CC BY 4.0), перерисованы программно: 50 мм/с, 10 мм/мВ, фильтр 0,05–40 Гц, режекция 50 Гц.
Два вида раскладки: 2 столбца по 2,8 с (I–aVF | V1–V6) и, для задач на ритм, 3 столбца по 1,86 с + ритмограмма II на 5,6 с.
Задача 17 — намеренно 5 мм/мВ. В задаче 1 электроды рук переставлены программно (I → −I, II ↔ III, aVR ↔ aVL) на нормальной ЭКГ; на самой ленте это не указано, чтобы не подсказать ответ.
Подпись с номером записи и лицензией внутри каждого SVG не обрезать.

Источник: Wagner P. et al. PTB-XL, a large publicly available electrocardiography dataset. Sci Data 7, 154 (2020); Goldberger A.L. et al. PhysioBank, PhysioToolkit, and PhysioNet. Circulation 101(23), 2000.
