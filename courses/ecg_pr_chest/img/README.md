# ЭКГ к курсу ecg_pr_chest

Все ленты — реальные записи базы PTB-XL (PhysioNet, лицензия CC BY 4.0), перерисованы программно:
50 мм/с, 10 мм/мВ (случай 13 — 5 мм/мВ намеренно), фильтр 0,05–40 Гц и режекция 50 Гц, по 2,8 с на столбец (I–aVF | V1–V6).
Внутри каждого SVG — подпись с номером записи и лицензией: не обрезать.

Источник: Wagner P. et al. PTB-XL, a large publicly available electrocardiography dataset. Sci Data 7, 154 (2020); Goldberger A.L. et al. PhysioBank, PhysioToolkit, and PhysioNet. Circulation 101(23), 2000.
