# Обновление базы КР при блокировке сайта Минздрава

`apicr.minzdrav.gov.ru` не отвечает зарубежным серверам (облако Claude, GitHub). Поэтому всё, что идёт с сайта Минздрава, делает телефон организатора (Android, учётка организатора в «Обучении и опросах»).

1. **Слежение** (`KrWatch.java`): раз в сутки телефон запрашивает список действующих КР (`op=GetJsonClinrecs`, запасной вариант — `GetJsonSpecialityClinrecs`) и сравнивает его с таблицей `cr` в базе приложения. Результат показывается на экране `#krnew` «Новое в КР», о новых находках приходит системное уведомление.
2. **Передача**: на экране «Новое в КР» → «Скачать и передать». Телефон скачивает тексты новых и обновлённых КР (`op=GetClinrec2`) и последний список рубрикатора. Всё отправляется POST-запросом на Google-скрипт отчётов (`learn.json → report`, `op: 'kr'`, ключ = READ_KEY организатора). Скрипт кладёт файлы в папку Google Диска «Справочник НМП — КР с телефона».
3. **Забрать здесь**: `python3 tools/kr_pull.py`. Тексты попадут в `/home/claude/cr/json/<id>.json.gz`, список — в `raw/list_phone.json`.
4. **Пересобрать**: обновить `raw/list.json` по списку с телефона, затем `build/build_db.py` → `cr.db` в assets → новый APK (`tools/publish_apk.sh`), потом `tools/kr_export.py` → ветка `kr`.

Код скрипта — `tools/google_results.gs`. В репозитории лежит версия с заглушкой ключа, настоящая — в закрытом архиве.
