# Тексты клинических рекомендаций для чата-редакции

Все действующие КР Минздрава России в виде текста (Markdown) — чтобы не выгружать их заново с сайта.

- `INDEX.md` — оглавление: ID, название, возраст, дата, МКБ-10, размер. `index.json` — то же для поиска.
- `kr/<ID>.md` — текст одной КР (например, `kr/400_2.md`). Самые длинные продолжаются в `kr/<ID>_part2.md`.
- Таблицы сохранены, рисунки — нет (на их месте «[рисунок]»; смотреть оригинал по ссылке в шапке файла).
- В шапке каждого файла: ID для ссылок в курсе (`КР400_2`), возраст, дата, МКБ-10, ссылка на оригинал.

Ветка обновляется из чата разработки: `python3 tools/kr_export.py <кэш_json> <папка>` (из ветки main).
