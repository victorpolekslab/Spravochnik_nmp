# Инструкции лекарственных препаратов для «Справочника НМП»

Ветка `drugs` — база официальных инструкций (ОХЛП) из Единого реестра зарегистрированных
лекарственных средств ЕАЭС. Приложение и сайт собираются из `main`; эта ветка только хранит данные.

## Что здесь

| Файл | Что внутри |
|---|---|
| `INDEX.md` | Оглавление: МНН, путь введения, препарат, АТХ, дата ОХЛП, доля OCR, ссылка на файл |
| `md/<МНН>__<путь>.md` | Текст одной ОХЛП, разбитый на разделы 1–10 (4.2 — дозы, 4.3 — противопоказания, 4.5 — взаимодействия) |
| `drugs_index.json` | Индекс для поиска в приложении: все действующие в РФ РУ ЕАЭС (торговое название, МНН, форма, путь, АТХ, держатель, `doc` — имя файла в `md/`) |
| `tools/` | Скрипты сборки |

## Как собрано

1. **Список.** Полная выгрузка реестра (ОП-26), обновляется ежедневно:
   `https://opendata.eaeunion.org/registry-archives/OP26_1.0.0_full.zip`.
   Берутся РУ со статусом «зарегистрировано» в РФ. Гомеопатия исключена
   (лекарственная форма «гомеопатические» или потенции D/C в составе). БАДов в реестре ЛС нет.
2. **Выбор документа.** Одна ОХЛП на пару «МНН + путь введения» (внутрь, парентерально, ингаляции,
   наружно, глаза…). Соли и гидраты одного вещества объединяются. Приоритет — оригинальный
   препарат, затем самая свежая ОХЛП. Если файл не отдаётся, берётся следующий кандидат.
3. **Текст.** Текстовый слой PDF (PyMuPDF). Страницы без текста распознаются Tesseract (rus+eng);
   в шапке файла указано, сколько страниц распознано автоматически.
4. **Разделы** находятся по нумерации и заголовкам ОХЛП (Решение Совета ЕЭК № 88).
5. **Дозагрузка из ГРЛС.** Для групп, у которых в открытых данных ЕАЭС нет файла ОХЛП, документ берётся
   из карточки РУ в ГРЛС (grls.rosminzdrav.ru). Там это либо национальная «Инструкция по медицинскому
   применению», либо листок-вкладыш ЕАЭС. Их разделы получают номера ОХЛП, чтобы приложение искало
   одинаково: показания — 4.1, дозы — 4.2, противопоказания — 4.3, взаимодействия — 4.5,
   нежелательные реакции — 4.8. Источник и тип документа указаны в шапке файла и в `INDEX.md`.

```
python3 tools/build_list.py <папка с OP26_*.json> out
python3 tools/fetch_texts.py out/pick.json full --workers 8     # можно прерывать и продолжать
python3 tools/grls_fetch.py out/index.json out/missing.json grls_out --workers 4   # недостающие из ГРЛС
python3 tools/grls_texts.py grls_out --workers 8
GRLS_DIR=grls_out python3 tools/build_index.py out full .  <папка с metadata.json>
```

## Ограничения

- **Охват.** 99,5 % записей индекса ссылаются на документ своего МНН и пути введения
  (2475 ОХЛП из реестра ЕАЭС + 1030 документов из ГРЛС). Препаратов, зарегистрированных только
  по национальным правилам и ещё не внесённых в реестр ЕАЭС, здесь нет.
- **Листок-вкладыш** (около половины документов из ГРЛС) написан для пациента: дозы и взаимодействия
  в нём есть, но короче и проще, чем в ОХЛП. Такие файлы помечены в шапке.
- **Одна ОХЛП на группу.** У дженериков могут отличаться вспомогательные вещества
  (а значит, отдельные противопоказания) и список показаний.
- **OCR.** Около 3 % страниц распознаны автоматически: в цифрах возможны ошибки.
  Такие документы помечены в шапке и в `INDEX.md` — дозы сверяйте с оригиналом.
- Справочная информация, не заменяет инструкцию к конкретному препарату и решение врача.
