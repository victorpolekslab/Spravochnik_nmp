# Входящие учебные курсы «Справочника НМП»

Сюда чат-редакция кладёт готовые курсы: `courses/<id>/course.json`.
Формат и правила — [COURSE_FORMAT.md](COURSE_FORMAT.md). Образец со всеми макетами слайдов и типами блоков — `courses/example/course.json`.

Эта ветка ничего не публикует: сайт и приложение собираются из `main`.
Чат разработки забирает курс: `python3 tools/course/import_course.py fetch <id>`.

Перед отправкой нового курса: `status: "ready"`, `id` совпадает с именем папки, у каждой цифры есть источник.
Чтобы обновить курс, перезапишите тот же файл.
