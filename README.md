# Справочник фельдшера неотложной медицинской помощи

Схемы обследования и лечения для фельдшера неотложной помощи (до приезда СМП), классификатор МКБ-10 с поиском
и загрузкой клинических рекомендаций Минздрава России, калькуляторы: ИМТ, шкала комы Глазго, индекс Альговера, ВАШ.

**Веб-версия (iPhone и любой браузер):** https://victorpolekslab.github.io/Spravochnik_nmp/
iPhone: открыть в Safari → «Поделиться» → «На экран Домой». Android: Chrome → «Установить приложение».
После первого открытия работает без интернета; интернет нужен только для загрузки полных текстов КР.

> Справочник не заменяет инструкцию к препарату и решение врача. Дозы с пометкой «КР» — из текста клинической
> рекомендации, «инстр.» — из инструкции к препарату.

## Устройство

| Папка | Что внутри |
|---|---|
| `android/` | Android-приложение (Java + WebView). Интерфейс и содержимое — `android/app/src/main/assets/www/`, база — `assets/cr.db` |
| `android/app/src/main/assets/www/content_*.js` | Разделы справочника: схемы, препараты, дозы, источники |
| `web/` | Веб-версия (PWA): `pwa.js` (данные через sql.js + IndexedDB), `sw.js` (офлайн и обновления), `build.py` (сборка) |
| `tools/` | Скрипты сборки базы КР и проверки доз по тексту рекомендаций |

Интерфейс общий: веб-версия собирается из тех же файлов `www/`, что и Android-приложение.

## Обновление

Любой коммит в `main` автоматически пересобирает и публикует веб-версию (GitHub Actions → GitHub Pages).
У пользователей при следующем открытии с интернетом появится «Доступна новая версия · Обновить».

Локальная сборка веб-версии: `cd web && npm install && python3 build.py` → `web/dist/`.
Android: `cd android && gradle assembleRelease` (для подписи релизным ключом нужен `android/keystore.properties`).
